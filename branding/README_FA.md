# هویت بصری بسته‌یاب — نسخهٔ ۱.۸.۰

- `bastehyab-app-icon.svg`: منبع برداری آیکون جدید؛ سپر امنیتی، بستهٔ اینترنت و نشانه‌های اسکن.
- `bastehyab-app-icon.png`: پیش‌نمایش PNG آیکون با پالت سرمه‌ای/فیروزه‌ای.
- `bastehyab-logo.svg`: لوگوتایپ برداری فارسی با همان نشان و پالت.
- `bastehyab-logo.png`: خروجی PNG بنر لوگو.
- `../app/src/main/res/drawable-nodpi/brand_mark.png`: نشان شفاف مشترک در لانچر و صفحهٔ آغازین برنامه.
- `../app/src/main/res/drawable/ic_launcher_bg.xml` و `ic_launcher_fg.xml`: اجزای آیکون Adaptive اندروید.
- `../app/src/main/res/drawable/ic_launcher_mono.xml`: نسخهٔ تک‌رنگ برای لانچرهای پشتیبان.

هویت جدید به‌جای تیک بنفش قبلی از سپر، بسته و چهار گوشهٔ اسکن استفاده می‌کند تا مفهوم بسته‌یاب و فضای امنیت شبکه را بدون جزئیات شلوغ منتقل کند. انیمیشن پس‌زمینه فقط در رابط برنامه اجرا می‌شود؛ لوگو و آیکون ثابت‌اند تا وضوح و خوانایی حفظ شود.
